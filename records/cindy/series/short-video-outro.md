# Short-video series: the fixed outro ("lab log")

Every short video in this series ends with the *same* outro card, so the clips read as one long
running log instead of unrelated videos. The layout, colours and typography never change;
only the numbers do.

## What the outro shows

| Element | Where the number comes from |
| --- | --- |
| Series identity | `CINDY TENNIS LAB` chip, top-left |
| Log number | `LOG No.NN` — increments once per entry |
| Date | shooting date of the footage |
| Sessions · clips · reports logged | counted from the archive (training folders, clips, written reports) |
| Days since the first record | days elapsed since the first training report |
| Current focus | the single skill being changed in the current 4-week block |
| Review-cycle bar | position inside the 14-day review cycle + days to the next review |
| Two standing rules | "只记过程，不记名次" (process only, never placing) · "一次只改一件事" (one change at a time) |
| Next-episode hook | one line teasing the following entry |
| Number stamp | bottom-right `No.NN` |

## Why it is designed this way

- **It is a log, not a poster.** The numbers have to grow over years, so the outro records
  cumulative work (days since the first record, sessions logged, reports written) instead of a result.
- **One fixed identity.** The same visual frame every episode lets a viewer follow the series
  without reading a caption; only the figures move.
- **Nothing about results.** No scores, no rankings, no placements — consistent with the rule that
  only process indicators count.
- **Safe area.** All text lives in the top 80 % of the frame; the bottom 20 % is deliberately empty
  because the platform draws its own UI there.

## Notes for re-use

- The outro is generated from the archive by a script, not hand-made each time; the numbers are
  computed from real counts so an episode cannot claim progress it has not logged.
- Entries are numbered once and never re-used; the series registry keeps the running number.
